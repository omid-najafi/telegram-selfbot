# 🤖 ربات سلف‌ساز تلگرام (Telegram Userbot)

رباتی که با اکانت کاربر لاگین میشه و هر کلمه‌ای که در گروه با پسوند **«روشن سرور»** نوشته بشه، هر ۵ دقیقه یکبار در همون گروه تکرار میکنه. با نوشتن **«خاموش سرور»** هم متوقف میشه.

## ✨ امکانات

- 🔐 لاگین با شماره تلفن، کد تایید و رمز ۲FA (در صورت نیاز)
- 📨 تکرار هر کلمه در گروه هر ۵ دقیقه (قابل تغییر)
- 🎯 کنترل از طریق ربات کنترل (Bot API) و گروه‌ها
- ☁️ آماده دیپلوی روی Railway.com
- 💾 ذخیره session به صورت string (بدون نیاز به فایل)

## 📁 ساختار پروژه

```
telegram-selfbot/
├── main.py             # کد اصلی ربات
├── requirements.txt    # وابستگی‌های پایتون
├── runtime.txt         # نسخه پایتون
├── Procfile            # دستور اجرا برای Railway
├── railway.json        # کانفیگ Railway
├── .env.example        # نمونه متغیرهای محیطی
├── .gitignore
└── README.md
```

## 🛠️ پیش‌نیازها

### ۱. گرفتن `API_ID` و `API_HASH`
1. به [my.telegram.org](https://my.telegram.org) برید.
2. وارد اکانت تلگرام بشید.
3. به بخش **API development tools** برید.
4. یک برنامه جدید بسازید (هر نام/توضیحی).
5. `api_id` و `api_hash` رو یادداشت کنید.

### ۲. ساخت ربات کنترل و گرفتن `BOT_TOKEN`
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدید.
2. دستور `/newbot` رو بفرستید.
3. یک نام و یوزرنیم انتخاب کنید.
4. توکن ربات رو یادداشت کنید.

### ۳. گرفتن `OWNER_ID` (آیدی عددی خودتون)
1. به [@userinfobot](https://t.me/userinfobot) پیام بدید.
2. آیدی عددی خودتون رو یادداشت کنید.

## 🚀 دیپلوی روی Railway

### مرحله ۱: آپلود به GitHub
1. یک ریپو جدید توی GitHub بسازید (مثلاً `telegram-selfbot`).
2. تمام فایل‌های این پوشه رو به ریپو پوش کنید:

```bash
cd telegram-selfbot
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/telegram-selfbot.git
git push -u origin main
```

### مرحله ۲: اتصال به Railway
1. به [railway.app](https://railway.app) برید و با GitHub وارد بشید.
2. روی **New Project** کلیک کنید.
3. **Deploy from GitHub repo** رو انتخاب کنید.
4. ریپو `telegram-selfbot` رو انتخاب کنید.
5. Railway به طور خودکار `requirements.txt` رو تشخیص میده و نصب میکنه.

### مرحله ۳: تنظیم متغیرهای محیطی
در صفحه پروژه روی تب **Variables** کلیک کنید و این‌ها رو اضافه کنید:

| متغیر | مقدار |
| --- | --- |
| `API_ID` | api_id از my.telegram.org |
| `API_HASH` | api_hash از my.telegram.org |
| `BOT_TOKEN` | توکن ربات از BotFather |
| `OWNER_ID` | آیدی عددی شما |
| `SESSION_STRING` | **فعلاً خالی بذارید** |
| `SEND_INTERVAL` | `300` (اختیاری، پیش‌فرض ۵ دقیقه) |

### مرحله ۴: دیپلوی اول
روی **Deploy** کلیک کنید. بعد از چند دقیقه ربات بالا میاد.

### مرحله ۵: لاگین اکانت کاربر
1. در تلگرام به ربات کنترل (همونی که با BotFather ساختید) پیام بدید و `/start` بزنید.
2. ربات میگه: «شماره تلفن رو با کد کشور بفرست.»
3. شماره رو بفرستید (مثلاً `+989123456789`).
4. ربات به تلگرام درخواست کد میفرسته.
5. کد تایید رو به ربات بفرستید.
6. اگر اکانت ۲FA داره، رمز رو بفرستید.
7. ربات پیام موفقیت میده و یک `SESSION_STRING` طولانی نشون میده.

### مرحله ۶: ست کردن `SESSION_STRING`
1. اون `SESSION_STRING` رو کپی کنید.
2. در Railway به تب **Variables** برید.
3. مقدار متغیر `SESSION_STRING` رو با این رشته پر کنید.
4. ری‌دیپلوی کنید (Railway خودش میکنه).

### مرحله ۷: استفاده 🎉
- در هر گروهی که اکانتتون عضو هست، بنویسید:
  - `سلام روشن سرور` → ربات هر ۵ دقیقه «سلام» رو میفرسته.
  - `سلام خاموش سرور` → متوقف میشه.

## 📋 دستورات ربات کنترل (چت خصوصی)

| دستور | کارایی |
| --- | --- |
| `/start` | شروع / اتصال اکانت |
| `/help` | نمایش راهنما |
| `/status` | وضعیت اکانت و ارسال‌های فعال |
| `/logout` | خروج از اکانت |

## ⚙️ تنظیمات پیشرفته

### تغییر فاصله ارسال
متغیر `SEND_INTERVAL` رو در Railway تغییر بدید. مقدار به **ثانیه** است.
- `60` = هر ۱ دقیقه
- `300` = هر ۵ دقیقه (پیش‌فرض)
- `600` = هر ۱۰ دقیقه

### محدودیت‌ها
- ⚠️ تلگرام محدودیت ارسال پیام داره. ارسال بیش از حد میتونه باعث محدود شدن اکانت بشه. فاصله کمتر از ۶۰ ثانیه توصیه نمیشه.
- ⚠️ اگر ربات ری‌استارت بشه، ارسال‌های فعال از بین میرن و باید دوباره دستور `روشن سرور` بدید.

## 🧪 اجرای محلی (تست)

```bash
# نصب وابستگی‌ها
pip install -r requirements.txt

# ست کردن متغیرها (یا در .env)
export API_ID=...
export API_HASH=...
export BOT_TOKEN=...
export OWNER_ID=...

# اجرا
python main.py
```

## 🔒 امنیت

- **هرگز** `SESSION_STRING` یا `API_HASH` رو در GitHub یا جایی عمومی نذارید.
- فایل `.env` در `.gitignore` هست.
- فقط `OWNER_ID` میتونه به ربات کنترل دستور بده.
- برای خروج کامل: `/logout` بزنید و `SESSION_STRING` رو از Railway پاک کنید.

## ❓ عیب‌یابی

| مشکل | راه‌حل |
| --- | --- |
| ربات در Railway کرش میکنه | لاگ‌ها رو در Railway چک کنید. احتمالاً متغیری ست نشده. |
| `SESSION_STRING` نامعتبر | دوباره `/start` بزنید و لاگین کنید. |
| کد تایید نمیاد | صبر کنید یا `/start` رو دوباره بزنید و دوباره شماره بفرستید. |
| ربات در گروه دستورات رو نمیبینه | مطمئن بشید اکانتتون عضو اون گروه هست. |
| ارسال کار نمیکنه | شاید دسترسی ارسال به گروه ندارید. یا اکانت محدود شده. |
